Halloween plague doctor voice changer for Android

Download APK How to install and use

Quick start

  1. Tap Download APK. If your phone asks, allow installing apps from your browser.
  2. Open the downloaded file and install it. Android may warn that the app is unknown - that is normal for a self-made APK.
  3. Turn on and pair your Bluetooth speaker / stereo first.
  4. Open Dottore della Peste, tap Refresh audio devices, and pick the Bluetooth speaker as the output.
  5. Tap Start voice changer and allow the microphone permission. Talk and enjoy.
